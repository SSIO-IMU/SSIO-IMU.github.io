Abstract

Learning inertial odometry for a new platform usually requires labeled trajectories. We show that an IMU integration teacher can train a velocity model from scratch without velocity or position labels. The teacher is myopic: it integrates each short window independently. The student learns from these short-window targets yet predicts long-horizon velocity changes more accurately than its teacher. Integration self-supervision draws its training signal from the input itself: over each window, the calibrated IMU samples are integrated into a velocity change, and the student's predicted velocities at the window endpoints must reproduce it. Optional pose graph distillation (PGD) then refines the student: one pose graph over many windows is solved for sequence-consistent velocities, which become fine-tuning targets for the student. A new embodiment then requires no motion capture, RTK, or SLAM ground truth, only unlabeled IMU recorded on the platform during normal operation. Across six datasets spanning pedestrians, drones, quadrupeds, and a humanoid, the same recipe applied unchanged trains inertial odometry comparable to a supervised AirIO baseline.

Methods

The training signal comes from the IMU input itself, not from a recorded trajectory:

  1. Integration self-supervision. A frozen integration teacher turns each short IMU window into a velocity change; the network's predicted velocities at the window endpoints must reproduce it.
  2. Pose graph distillation (PGD). One full-sequence pose graph built from the teacher's IMU factors and the network's velocity factors is solved for sequence-consistent velocities, which then supervise the network.

Proprioceptive Input

On the three articulated platforms that log proprioception, feeding joint states to the student (and, on MIPO, the four calf-mounted IMUs) lowers both velocity and trajectory error, with the teacher and loss unchanged.
